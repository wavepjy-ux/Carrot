# 당근마켓 전국 통합 검색기 (Windows PC)

비공식 데스크톱 프로그램입니다. 키워드 검색 시:

1. 당근 `in=all` 검색 결과를 수집하고,  
2. 추가로 사이트맵(sitemap) 기반으로 전국 매물 URL을 스캔해 키워드 매칭 결과를 보강합니다.

즉, 기존처럼 근처 위주로만 보이거나 누락되는 경우를 줄이기 위한 방식입니다.

> ⚠️ 주의: 이 프로그램은 공식 API가 아닌 공개 웹 페이지/사이트맵을 기반으로 동작합니다. 정책/구조 변경 시 동작이 달라질 수 있습니다.

## 기능

- 키워드 검색
- `전국 보강(사이트맵 스캔)` 옵션으로 전국 매물 보강
- `전국만(로컬검색 제외)` 옵션으로 위치 편향 가능성이 있는 기본 검색을 건너뛰고 사이트맵 기반만 사용
- 중복 제거
- 목록 더블클릭 또는 `선택 상품 열기` 버튼으로 상품 페이지 열기
- `선택 사진 열기`로 사진 URL 열기
- CSV 저장 (`source`, `image_url` 포함)

## 실행

```bash
python app.py
```

## 사용 팁

- 전국 범위를 최대화하려면 `전국 보강(사이트맵 스캔)`을 켜고 `최대 페이지`를 10~20으로 사용하세요.
- 로컬 편향이 의심되면 `전국만(로컬검색 제외)`를 켜서 사이트맵 기반 결과만 보세요.
- 페이지를 크게 줄수록 결과는 늘 수 있지만 검색 시간이 길어질 수 있습니다.

## exe 만들기 (선택)

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed app.py
```

생성 파일: `dist/app.exe`

## 한계

- 사이트맵에 아직 반영되지 않은 최신 글은 누락될 수 있음
- 로그인/권한 이슈가 있는 글은 메타데이터 파싱이 제한될 수 있음
- 네트워크 상태/차단 정책에 따라 결과 수가 달라질 수 있음
