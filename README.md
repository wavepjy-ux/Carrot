# 당근마켓 전국 통합 검색기 (Windows PC)

비공식 데스크톱 프로그램입니다. 키워드를 입력하면 당근마켓 웹 검색(`in=all`) + 웹 인덱스(검색엔진 색인) 결과를 합쳐서 최대한 전국 매물을 모아 보여줍니다.

> ⚠️ 주의: 이 프로그램은 공식 API가 아닌 공개 웹 페이지를 기반으로 동작합니다. 서비스 정책/구조 변경 시 동작이 달라질 수 있습니다.

## 기능

- 키워드로 당근마켓 매물 검색
- `전국 보강(웹 인덱스 포함)` 옵션으로 당근 검색에서 누락되는 전국 매물 보강
- 여러 페이지 자동 순회 + 중복 URL 제거
- 목록 더블클릭 또는 `선택 상품 열기` 버튼으로 상품 페이지 열기
- `선택 사진 열기`로 사진 URL 열기
- 결과 CSV 저장 (`source`, `image_url` 포함)

## 실행 방법 (Windows)

1. Python 3.11+ 설치
2. 터미널에서 프로젝트 폴더로 이동
3. 실행:

```bash
python app.py
```

## 사용 방법

1. `키워드` 입력 (예: 아이폰, 자전거)
2. `최대 페이지` 입력 (권장 5~20)
3. `전국 보강(웹 인덱스 포함)` 체크 상태에서 `검색 시작`
4. 결과에서 상품 선택 후:
   - 더블클릭 또는 `선택 상품 열기`: 상품 페이지 열기
   - `선택 사진 열기`: 사진 URL 열기
5. 필요시 `CSV 저장`

## exe로 만들기 (선택)

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed app.py
```

생성 파일: `dist/app.exe`
