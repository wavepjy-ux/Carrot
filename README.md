# 당근마켓 전국 통합 검색기 (Windows PC)

비공식 데스크톱 프로그램입니다. 키워드를 입력하면 당근마켓 웹 검색(`in=all`) 페이지를 여러 페이지 순회해서 결과를 한 번에 모아 보여줍니다.

> ⚠️ 주의: 이 프로그램은 공식 API가 아닌 공개 웹 페이지를 기반으로 동작합니다. 서비스 정책/구조 변경 시 동작이 달라질 수 있습니다.

## 기능

- 키워드로 당근마켓 매물 검색
- 여러 페이지를 자동 순회해 최대한 많이 수집
- 중복 URL 제거
- 결과를 CSV로 저장

## 실행 방법 (Windows)

1. Python 3.11+ 설치
2. 터미널에서 프로젝트 폴더로 이동
3. 실행:

```bash
python app.py
```

## 사용 방법

1. `키워드` 입력 (예: 아이폰, 자전거)
2. `최대 페이지` 입력 (권장 5~20)
3. `검색 시작` 클릭
4. 결과 확인 후 `CSV 저장`

## exe로 만들기 (선택)

PyInstaller를 사용하면 단일 실행 파일로 배포할 수 있습니다.

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed app.py
```

생성 파일: `dist/app.exe`
